# Промпт для чистого чата

Используйте этот файл только когда предыдущий агент явно выбрал новый чат на настоящей границе работы: для независимого work item, осознанной паузы или продолжения, которое нельзя безопасно восстановить из канонических файлов. Обычная правка, тест, commit, push, короткий вопрос или смена фазы сами по себе не требуют нового чата.

```text
Работай по каноническим файлам проекта, а не по предположениям из прошлых чатов.

1. Полностью прочитай AGENTS.md, control/WORKSPACE-PROFILE.yaml и control/NOW.yaml.
2. Если `last_handoff` в NOW не `null`, прочитай его как последний переносимый checkpoint; при расхождении следуй NOW и каноническим BMAD artifacts.
3. Открой только next_action.input_paths и файлы, на которые они непосредственно ссылаются.
4. Выполни ровно текущий пользовательский результат из next_action. Не начинай соседнюю независимую работу.
5. Если не хватает существенного решения владельца, задай один короткий вопрос в этом же чате. `blocked` и новый `ask-owner` записывай только когда это состояние должно пережить чат.
6. После долговечного изменения сохрани evidence при необходимости, обнови владельца факта и NOW.yaml, затем выполни обычные precommit → commit → push в подтверждённый remote → postcommit.
7. Создай immutable handoff и обнови NOW.last_handoff только перед реальной передачей, значимым milestone или запланированной паузой. Тогда handoff входит в этот же commit с его marker и также проходит precommit/push/postcommit.

Чат — не память проекта. Не добавляй второй delivery module, Loop, Build Auto или внешний SDD engine, если это не закреплено в профиле и решении.
```
