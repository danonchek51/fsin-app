# Долговечное знание проекта

Здесь хранятся короткие подтверждённые документы, которые нужны нескольким work items: устав, архитектурные решения, доменные правила, runbooks и глоссарий.

Не копируйте сюда автоматически requirements, stories, очереди или lifecycle из BMAD artifacts. Вместо копии дайте ссылку на их канонический путь. Если документ устарел, пометьте его `superseded` и укажите замену.

Новый факт попадает в `docs/`, только если он переживёт текущий action и полезен следующему чату.
