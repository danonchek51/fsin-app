# Пример личного `~/.codex/AGENTS.md`

Это **не** файл проекта и его не нужно копировать в репозиторий. Здесь допустимы только устойчивые личные правила, применимые ко всем вашим проектам.

```md
# Личные правила

- Общайся по-русски, если не указано иное.
- Не раскрывай секреты и не коммить machine-local конфигурацию.
- Перед существенным изменением прочитай project `AGENTS.md` и `control/NOW.yaml`.
- Не считай историю чата источником истины: сохраняй важные решения в проектных artifacts.
- Перед handoff запускай проектную проверку или явно фиксируй, почему она невозможна.
```

Не помещайте сюда названия проектов, пути, статусы, backlog, конкретные BMAD modules, команды сборки или правила одного репозитория: всё это принадлежит project-level файлам.
