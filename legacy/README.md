# Исторические материалы

Сюда помещайте только superseded contracts, старые exports и материалы миграции, которые полезны как доказательство прошлого, но не должны управлять текущей работой.

Каждый импортированный набор должен иметь короткий `README.md` с источником, датой импорта, статусом и ссылкой на действующий replacement. Ничего из `legacy/` не читается новым чатом без явной ссылки из текущего action.
