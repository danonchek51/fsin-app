# Необязательные интеграции

Базовый шаблон не содержит интеграций. Если проекту нужна внешняя система, подключайте её отдельным пакетом только после decision, в котором зафиксированы:

- зачем нужна интеграция и какая информация остаётся канонической вне неё;
- какие данные и конфигурация versioned, а какие остаются `*.local.*`;
- как исключаются секреты, персональные данные, UUID и абсолютные пути;
- как новый чат продолжает работу без доступа к личному UI или истории чата.

Интеграция не получает право создавать конкурирующие requirements, backlog, workflow state или handoff.
